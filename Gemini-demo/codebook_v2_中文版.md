# BPLL 编码手册 Codebook v2（中文版）

**项目名称：** Beauty Brand Purchase-Legitimacy Lexicon（BPLL）  
**版本：** v2.0.1  
**更新日期：** 2026-10-12  

---

## 0. v2 为什么需要重建

在最开始的V1版本中，我们先进行了两轮各 50 条的试标，随后又由 3 名标注者完成了约 300 条正式样本。在分析中，我们发现，每一个标注者对于不同标签都有不同的判准。
深入研究后，我们发现了问题：事实上，购买理由、危机反应、转换阶段、消费结果和样本资格，本来就不在同一个层面。
例如，“替代转投”是行为过程，“安全恐慌”是原因机制，“割舍挣扎”是心理或决策状态，“主题无关”则是样本边界。它们完全可能在同一条文本中同时成立，却曾被放在同一套分类里竞争位置。标准自然很难统一。

在v2 中，我们试图把不同的问题拆开，每一层只回答一件事。

1. 文本中的行为主体是谁？
2. 该主体与本条记录的目标品牌是什么关系？
3. 文本直接证明了什么品牌消费结果？
4. 消费者处于什么转换阶段？
5. 什么力量支持留存或推动退出？
6. 文本是否在制造公开抵制或社会压力？
7. 每个判断由哪一段原文支持？

v2 认为：**负面声量不等于客户流失；品牌客户流失必须同时具备目标品牌客户关系证据与退出证据。**

## 1. 研究问题与可回答边界

### 1.1 主问题

> 当品牌因原产国事件遭遇合法性危机时，哪些目标品牌客户仍然留存，哪些客户产生或完成退出；他们分别基于什么理由作出选择？

本项目只有一个主问题。下文的编码层级是回答该问题所需的测量步骤，不是彼此独立的多个研究问题。

### 1.2 本项目能够回答什么

- 公开文本中，哪些发言提供了目标品牌留存、退出意图或已经退出的证据；
- 留存与退出分别受到哪些产品价值、转换成本、安全、信任、政治与社会压力机制影响；
- 公开抵制话语与可观察的个人消费行为之间有多大差距；
- 从“仍在使用库存”到“寻找替代”“替代成功或失败”的转换路径如何展开。

### 1.3 本项目不能直接回答什么

- 不能仅凭一条发言断言某个人将永久留存；“留存”只指文本所覆盖时间点的可观察状态；
- 不能把没有发声的消费者纳入推断；
- 不能把抵制口号直接换算成真实销量或客户流失率；
- 不能根据发言者未说出的动机，推断其真实心理；
- 不能用探索性、危机富集或关键案例样本估计总体占比。

正式报告中，宜使用“文本中可观察的留存/退出”“表达出的退出意图”等措辞，避免将话语直接写成交易事实。

## 2. 分析单位与目标品牌规则

### 2.1 分析单位

分析单位为：

> **一条社交媒体发言 × 该数据行的目标品牌（target brand）**

目标品牌以数据字段 `brand_category` 为准，而不是由标注者自由选择。

如果同一段文本以不同目标品牌形成多条数据行，则每一行均应围绕各自目标品牌重新判断。一个人可以是资生堂的既有客户，同时只是花王的潜在客户。

### 2.2 品牌关系只按目标品牌计算

- 明确买过或使用过目标品牌：既有/既往客户；
- 没用过目标品牌，但属于相关美妆品类消费者，或明确考虑购买目标品牌：目标品牌潜在客户；
- 只使用过无印良品、优衣库等非美妆品牌，且未表达对目标品牌或相关美妆品类的购买可能：不能据此认定为目标品牌潜客；
- 使用过资生堂但未使用花王：若该行目标品牌为资生堂，则是资生堂客户；若目标品牌为花王，则最多是花王潜客，不能算花王客户。

### 2.3 品牌、产品与昵称

消费者不会总按官网全名说话。“红腰子”通常指资生堂相关产品，“神仙水”通常指 SK-II 护肤精华露；文本中还会出现英文名、错拼、子品牌和集团品牌。标注者如果临场凭印象认品牌，同一句话很容易被判成不同的客户关系。

因此，Demo 使用随 v2.0.1 发布并已经审核冻结的 `brand_alias_map.csv`。映射表不仅列“它可能是谁”，还说明该叫法是否需要上下文、是否属于同集团独立品牌，以及能否参与目标品牌 R1 的判断。这里最重要的一条仍然没变：映射表只负责认出实体；品牌或产品名的单纯出现不构成购买史，R1 仍须同一发言中的购买、使用、囤货或回购证据。

本轮冻结的范围口径包括：CPB、安热沙、怡丽丝尔、IPSA 等不自动计入资生堂品牌 R1；珂润、碧柔、乐而雅等不自动计入花王品牌 R1；悦薇/REVITAL 暂按资生堂目标产品线处理，并保留边界说明。完整的 5 条范围裁决见 `brand_scope_decisions_v2.csv`。

## 3. 总体编码流程

每条文本严格按以下顺序编码。

1. **确认目标品牌**：读取 `brand_category`。
2. **确认声音来源**：本人、转述个人、机构/媒体，或者不明。
3. **确认目标品牌关系**：既有客户、潜客、其他品类用户、非个人材料或无法确认。
4. **确认消费结果**：只编码文本直接支持的结果，不进行因果脑补。
5. **标记转换阶段**：允许多选。
6. **标记留存与退出机制**：允许多选。
7. **标记公开话语行为**：允许多选，且与个人消费结果相互独立。
8. **复制证据原文**：分别记录关系证据、结果证据与机制证据。
9. **记录推断但不把推断当标签**：合理猜测写入研究者备注。

## 4. 字段 V：Voice，声音来源（单选）

该字段回答：**文本中的消费判断来自谁？**

| 代码 | 标签 | 定义 |
|---|---|---|
| V1 | 第一人称本人 | 发言者描述自己的购买、使用、犹豫或退出 |
| V2 | 被转述的具体个人 | 发言者明确引用朋友、家人、同事等人的消费行为 |
| V3 | 机构/媒体/渠道材料 | 新闻、品牌声明、带货团队、电商观察、行业分析或聚合性描述 |
| V4 | 来源无法确认 | 文本过短、主语缺失或上下文不足 |

### V 字段边界

- “L 同学说：那我不管，我就要用资生堂”属于 V2，不属于发帖者本人的 V1；
- “多家日妆品牌遭遇退货”属于 V3，不能据此生成一个具体客户；
- 转发新闻时附带“我以后不买了”，个人附言部分仍可编码 V1；
- 媒体正文与个人附言应分别取证。

## 5. 字段 R：Relationship，目标品牌关系（单选）

该字段回答：**文本中的行为主体在危机前或当前是否已经是目标品牌客户？**

### R1｜目标品牌既有/既往客户

**定义：**原文明确表示本人或被转述个人买过、用过、囤有、回购过目标品牌或其已冻结映射中的产品。

**算：**

- “我平时用的就有花王。”
- “红腰子回购过很多次。”
- “手里还剩两瓶神仙水。”

**不算：**

- 只列出目标品牌名称；
- “谁还买资生堂”（没有说明本人买过）；
- 使用过其他日系品牌，但没有使用目标品牌（例如使用过无印良品，但没有使用过目标品牌如资生堂）。

### R2｜目标品牌潜在客户

**定义：**没有目标品牌既有使用证据，但满足以下至少一项：

1. 明确表达曾经或正在考虑购买目标品牌；
2. 明确属于相关美妆/日化品类消费者，并在文本中把目标品牌纳入选择、比较、放弃或规避范围。

**算：**

- “本来想转正以后买 SK-II，现在不考虑了。”
- 使用资生堂护肤品、没有花王使用史，但在花王目标行中讨论是否选择花王同品类产品。
- 使用过非美妆日系品牌，同时明确说“本来想买资生堂”。

**不算：**

- 没有表达对目标美妆品牌的考虑；
- 单纯复制日货清单；
- 单纯辱骂或号召抵制。

### R3｜非目标品牌用户/其他品类用户

**定义：**文本明确提供了消费经历，但经历仅属于其他无关品类或品牌，且没有形成对目标品牌的明确考虑。

例：“我以前爱买优衣库，从现在起不买了”，当目标品牌是资生堂但贴中没有任何美妆购买意图时，属于 R3。

### R4｜渠道、媒体或非个人消费材料

**定义：**文本主要提供新闻、行业判断、品牌声明或销售渠道观察，无法对应一个具体消费者关系。

### R5｜无法确认关系

**定义：**文本与目标品牌有关，但没有足够信息判断其属于 R1—R4 中哪一种。

### R 字段规则

1. 目标品牌的客户关系不能由其他品牌使用史替代。
2. 话题标签、品牌清单、辱骂与号召均不是购买史。
3. R1 是进入“既有客户流失”统计的必要条件。
4. R2 的流失只能称为“潜在购买机会流失”，不能并入既有客户流失。

## 6. 字段 O：Outcome，目标品牌消费结果（单选）

该字段回答：**截至文本最后可观察的时间点，目标品牌的消费方向是什么？**

O 字段只保留文本最后能够观察到的去留结果。库存、寻找替代、替代成败等过程放入 T 字段；支持留存或推动退出的原因放入 MR/MX 字段。
若同一文本中先退出、后因替代失败重新购买，应按最后出现的状态编码 O，并在 T 中保留完整路径。

### O1｜确认继续/危机后留存

**定义：**存在危机发生后的实际购买、继续使用、再次购买或明确继续购买意图。

**必须满足：**

- 对 R1：有危机后的行为或清楚的未来继续意图；
- 对 R2：明确表示危机后仍准备首次购买，可在备注中标为“潜在客户保留”，但不得计入既有客户留存率。

**算：**“其实不想买，因为核废水，但那个味道太好闻，我还是又买了。”

**不算：**

- 只说“很好用”，没有危机后的行为方向；
- 只问“还能不能用”；
- 仍在消耗旧库存但明确说不再复购。

### O2｜未决

**定义：**R1 客户仍处于使用关系中，但正在犹豫、求证或评估，文本没有形成明确继续或退出决定。

**算：**

- “我的敏感肌离不开它，但现在还能用吗？”
- 刚买完后因品牌声明产生担忧，尚未决定退货或继续。

**不算：**已经明确说“用完不再买”；该情形属于 O3。

### O3｜明确退出意图/未来不复购

**定义：**R1 客户明确表示将停止购买或使用目标品牌，但退出尚未完全执行，或仍在消耗库存。

**算：**

- “手里的用完就不买了。”
- “这是最后一批，以后不会回购。”

**注意：**仍在使用库存不等于留存。若未来不复购意图已经明确，应编码 O3，并在 T 字段选择 T1“库存过渡”。

### O4｜退出已经执行

**定义：**R1 客户已经停止使用、退货、送走、丢弃、换掉目标品牌，或明确描述实际切换行为。与 O3 的区别在于：O3 可以是“用完库存就不再买”，O4 则必须已经发生至少一个退出动作。

**算：**

- “神仙水已经送人了。”
- “以前一直用花王，现在换成了其他品牌。”

### O5｜潜在购买机会流失

**定义：**R2 潜客明确表示因危机不再考虑首次购买目标品牌，或撤回此前的购买计划。

**算：**“以前想着转正后买 SK-II，现在肯定不会买了。”

**不算：**

- 只说自己没用过 SK-II；
- 因 SK-II 新闻联想到安耐晒安全，但没有表达对 SK-II 的购买计划或放弃；
- 一般性“抵制日货”，没有目标品牌个人选择证据。

### O6｜没有可观察的个人消费结果

**定义：**文本内容完整，也可能具有强烈态度，但没有提供目标品牌个人消费行为或决策证据。

**算：**

- “让你们倒闭，让你们死。”
- “国货不香吗，谁还买日货。”
- “后续想买的建议走正规渠道”——只能证明建议的存在，不能证明发言者本人购买。

### O7｜上下文不足

**定义：**由于缺图、缺视频、指代不明、文本截断或其他上下文缺失，无法判断消费结果。

O6 与 O7 的区别：O6 是“文本完整，但没有个人结果”；O7 是“材料不完整，所以不能判断”。

## 7. 字段 T：Transition，转换过程（多选）

该字段回答：**消费者为继续、延迟或完成退出，采取了哪些可观察步骤？**

| 代码 | 标签 | 判定标准 |
|---|---|---|
| T1 | 库存过渡/最后囤货 | 仍有存货、计划用完退出，或因危机进行最后一次囤货 |
| T2 | 寻找/比较替代 | 求推荐、搜索、研究或比较替代品 |
| T3 | 已购买/试用替代，效果未定 | 替代品已经获得，但尚无使用结果 |
| T4 | 替代成功 | 替代品已使用，并满足关键需求或进入回购名单 |
| T5 | 替代失败 | 替代品效果、适配、价格或体验明显不满足需求 |
| T6 | 处置目标产品 | 退货、送人、丢弃或停止使用现有产品 |
| T7 | 回流目标品牌 | 曾试图退出，但因替代失败等原因重新购买或恢复使用 |

### T 字段规则

- 允许多选。例如，“用完库存，同时寻找替代”应标 T1 + T2；
- “已换掉且替代好用”应标 T4，若原文还说明送走原产品，可同时标 T6；
- “多次寻找替代但都不好用/不合适”应标 T2 + T5；
- 只说“找了很多次”，却没有交代替代品好不好用，应只标 T2；
- “替代失败”不自动等于回流；只有明确重新购买或继续使用目标品牌，才标 T7；
- 替代成功必须证明替代品满足需求；仅仅重新囤另一品牌不能自动判 T4；
- 转换阶段不是最终消费结果。O 与 T 必须分别编码。

## 8. 字段 MR：Retention Mechanism，留存护城河（多选）

该组回答：**什么因素使消费者继续、延迟退出，或产生回流可能？**

MR 与 MX 中的 M 均指 Mechanism；R 代表 Retention，X 代表 Exit。

### MR1｜功效与个体适配

产品在效果、肤感、皮肤/身体适配方面具有明确优势。

例：“换回悦薇的一瞬间整张脸都舒服了”“只有这个不会让我过敏”。

### MR2｜感官体验、习惯与情感依恋

气味、触感、长期使用习惯、熟悉感或情感依恋提高放弃成本。

例：“那个味道太好闻，连续用了很多年。”

### MR3｜转换风险

担心尝试新产品导致过敏、烂脸、效果波动或其他损失。

例：“敏感肌不敢乱试，怕踩雷。”

### MR4｜替代品稀缺或明显较差

找不到同等产品，或替代品在效果、价格、使用感等方面失败。

例：“又没有替代的”“欧美产品又贵又不吸收”。

### MR5｜可信的风险缓释与来源控制

因第三方检测、监管、产地、批次、正规渠道或可追溯性而认为风险可控。

例：“只买经过海关检测、来源明确的批次。”

### MR6｜不可避免/风险普遍化

认为污染无法躲避、全球供应链都含日本原料，因而放弃通过退出目标品牌规避风险。

例：“只要还用水就逃不过，单纯不买日系也没有用。”

### MR7｜消费自主与反道德绑架

因反感他人干预消费选择、强调“我的钱我决定”，而拒绝参与抵制。

例：“别人继续买也别道德绑架，别人的钱不是你的钱。”

## 9. 字段 MX：Exit Mechanism，退出压力（多选）

该组回答：**什么因素推动消费者做出退出选择（包括放弃首次购买或要求他人抵制）？**

### MX1｜产品安全与健康风险

担心核辐射、污染、致癌、长期累积伤害或产品原料不安全。核心担忧是“这个产品会不会伤害我”。

### MX2｜信息与制度信任崩塌

不相信日本政府、企业、检测报告、客服声明或监管过程。核心并不完全来自风险本身，而是对对方的身份怀疑：你说安全，我为什么相信？

包括：

- 企业自证，被视为利益相关者无论如何都可以自圆其说；
- 长期风险无法被短期检测排除；
- 品牌越急于强调安全，越引发“此地无银三百两”式怀疑。

### MX3｜原产国连带/日本属性污染

没有针对目标品牌的产品级证据，仅因其属于日本品牌、日本资本或日本供应链而受到连带否定。

该标签可与 MX1、MX2、MX4 同时存在。

### MX4｜经济惩罚与政治施压

将拒绝购买理解为打击日本企业、影响日本经济，并间接迫使日本政府改变行为。

例：“不买他们的产品，让资本家去给政府施压。”

该标签可能与 MX5、MX6 同时存在。

### MX5｜国家身份与道德义务

发言者以“我是中国人”“民族气节”“原则和底线”等理由约束自己的消费选择。

核心问题是“作为某种身份的人，我是否应该购买”。

该标签可能与 MX4、MX6、MX7 同时存在。

### MX6｜社会惩罚与负面身份信号

购买目标品牌会使消费者受到他人轻视、羞辱、道德审判或“汉奸”等身份指控。

该标签是当前语料对“社会信号翻转”最直接的可观察形式。它支持“日本属性在危机中可能转化为负面身份信号”，但不能单独证明化妆品普遍被用于炫耀或彰显阶层。

该标签可能与 MX4、MX5 同时存在。

### MX7｜危机前价值已经不足

价格虚高、产品效果一般、品牌竞争力下降等问题在危机前已经存在，而危机只是最后一根稻草、退出借口或加速器。

例：“本来就觉得太贵，现在正好有理由不买。”

该标签可能与 MX5 同时存在。

### MX8｜替代品吸引力/可获得性

国货、欧美或其他品牌已经能够满足需求，使退出成本下降。该标签强调替代品的拉力；T4“替代成功”记录实际过程，可以同时标注二者。

## 10. 字段 D：Discourse，公开话语行为（多选）

该组回答：**这条文本在公共讨论中做了什么？** 它不回答发言者本人是否为客户。

| 代码 | 标签 | 定义 |
|---|---|---|
| D1 | 公开抵制表态/集体号召 | 公开表达抵制、拒绝或希望品牌受损；也包括呼吁他人不买、扩散名单或共同打击日货 |
| D2 | 对购买者实施道德或身份惩罚 | 嘲笑、羞辱、威胁或给继续购买者贴政治身份标签 |
| D3 | 风险警告/避雷信息 | 发布产品、产地、批次、辐射或健康风险警告 |
| D4 | 风险缓释/继续购买建议 | 提供正规渠道、产地识别、检测或理性购买建议 |

### D 字段与个人结果的组合

- 单纯讲述个人退出，不自动标 D1。例如“我用了过敏，所以换了”只是个人消费结果；只有原文明确带有抵制、惩罚或集体行动立场时，才标 D1；
- 没有消费史但号召抵制：R5 + O6 + D1；
- 既有客户明确退出，同时号召他人抵制：R1 + O3/O4 + D1；
- 没有说明自己是否购买，只攻击继续购买者：R5 + O6 + D2；
- 媒体报道“品牌遭遇退货”：V3 + R4 + O6，是否标 D3 取决于文本是否主动发出风险警告；
- D2必须直接贬损、羞辱或污名化购买者，而“搞不懂为什么大家XXX”这种程度则不算；

因此，“公开抵制”不再与“明确退出”竞争同一个标签位置。

## 11. 字段 E：Evidence，证据字段与推断纪律

每条记录至少保留三个证据字段：

1. `relationship_evidence`：证明目标品牌关系的最短原文；
2. `outcome_evidence`：证明继续、退出或未决结果的最短原文；
3. `mechanism_evidence`：证明各机制标签的原文，可多段。

### 11.1 证据等级

| 代码 | 等级 | 规则 |
|---|---|---|
| E1 | 原文直接表达 | 标签与原文几乎同义，例如“以后不会再买” |
| E2 | 多句共同支持 | 需要连接同一文本中的两句，但没有补入未说出的动机 |
| E3 | 研究者推断 | 合理却缺乏文本直接证据，只能写入备注，不得作为 gold label |

### 11.2 典型越界

- 原文只说“很好用”，研究者认为“大概率还会买”：结果应为 O2 或 O6，不能标 O1；
- 原文只说“国货不香吗”，研究者认为“他正在找替代”：不能标 T2；
- 原文说“SK-II 没用过，但想到刚到货的安耐晒”：可以标风险联想，但不能据此认定 SK-II 首购已经流失；
- 原文使用政治性话题标签，但正文只谈安全：不能仅凭标签补入政治动机；
- “媲美某产品”可作为 R1 的间接证据，但通常是 E2、medium。

研究者可以在 `hypothesis_note` 中保留“可能继续购买”“可能是社会价值贬损”等洞察，供后续形成假设，但模型准确率只根据 E1/E2 标签计算。

## 12. 核心消歧规则

### 12.1 好用 ≠ 留存

“好用”属于 MR1，但只有出现危机后的继续行为或明确意图，才能标 O1。

### 12.2 仍在使用库存 ≠ 留存

若已经明确不再复购，则标 O3 + T1，不标 O1。

### 12.3 寻找替代 ≠ 已经退出

若仍在搜索且没有明确不复购，只能标 O2 + T2。若同时明确说“以后不买”，则标 O3 + T2。

### 12.4 替代失败 ≠ 必然回流

只有明确重新购买、恢复使用目标品牌时才标 T7，并据最终状态判断是否为 O1。

### 12.5 抵制口号 ≠ 个人退出

没有目标品牌关系与个人行动证据时，使用 O6 + D1/D2，不计入客户流失。

### 12.6 安全担忧与政治抵制可以同时存在

- “怕产品含辐射”标 MX1；
- “不买是为了打击日本经济”标 MX4；
- “我是中国人所以不能买”标 MX5；
- 原文均明确出现时允许多选，不强求一个主因。

### 12.7 自证安全可能被接受、无效或反噬

- 因第三方检测或来源透明而继续购买：MR5；
- 认为检测不足：MX2；
- 因品牌反复声明反而开始担忧：MX2，并在备注记录“自证反噬”。

### 12.8 “无法判断”与“多重状态”不再合并

v2 不设“无法判断/多重状态”混合标签：

- 证据不足使用 R5、O6 或 O7；
- 同时出现多个转换过程或机制，直接在 T、M、D 字段多选；
- 最终消费结果按文本最后可观察轨迹在 O 字段单选。

## 13. 七个裁决示例

### 示例 1｜危机后仍买：真实留存

> “其实不想买，因为核废水，但那个味道真的很好闻，连着用了好几年，最后还是又买了。”

- R1 目标品牌既有客户
- O1 确认继续/危机后留存
- MR2 感官体验、习惯与依恋
- MX1 产品安全风险（若上下文明确担忧）
- 关系与结果均需保留原文证据

### 示例 2｜有库存但已经决定离开

> “已经不会再买了，只是目前还有存货，想知道有没有替代产品。”

- R1
- O3 明确退出意图
- T1 库存过渡
- T2 寻找替代
- 不标 O1

### 示例 3｜退出与替代成功同时成立

> “为了安全把神仙水送人了，用了一年的花王产品也换成了其他品牌。”

- 对相应目标品牌：R1 + O4
- T4 替代成功（仅在原文证明替代品满足需求时）
- T6 处置目标产品
- MX1 安全风险
- 这不是“无法判断”，也不需要把多个过程压成一个标签

### 示例 4｜强烈抵制但没有客户行动

> “就算检测安全又怎样，现在就是让你们倒闭。”

- R5 无法确认关系
- O6 没有可观察的个人消费结果
- D1 公开抵制/集体号召
- 可标 MX4，但只有文本明确表达经济惩罚逻辑时才标

### 示例 5｜其他品类消费者，不是目标品牌客户

> “我本来不用日本护肤品，以前爱买优衣库，现在也不买了。”

- 若目标品牌为资生堂：R3
- O6
- D1（若文本具有公开抵制含义）
- 不计入资生堂既有客户流失或潜客流失

### 示例 6｜风险缓释建议，不等于发言者本人留存

> “后续想买的注意别买日代，建议走旗舰店或正规渠道。”

- 若没有本人消费史：R5
- O6
- D4 风险缓释/继续购买建议
- 不能标 O1

### 示例 7｜目标品牌潜客放弃

> “以前想着以后可以买 SK-II，现在是肯定不会买了。”

- 目标品牌为 SK-II：R2
- O5 潜在购买机会流失
- 不能计入 SK-II 既有客户流失

## 14. 派生指标与统计口径

所有派生指标必须同时使用 R 与 O，禁止只根据情绪或抵制标签统计客户流失。

### 14.1 既有客户结果

- **确认留存：** R1 + O1
- **高风险/未决：** R1 + O2
- **承诺退出：** R1 + O3
- **已执行退出：** R1 + O4
- **既有客户可观察流失：**分别报告 O3 与 O4；如需合并，命名为“表达退出方向的既有客户发言”，不可直接称真实销量流失率。

### 14.2 潜客结果

- **潜客机会流失：** R2 + O5
- 潜客数据必须与既有客户结果分开报告。

### 14.3 舆论压力

- D1/D2 可衡量公开抵制与社会惩罚话语；
- D1/D2 的分母是相关发言，不是客户；
- 可比较“抵制声量”与“有客户关系证据的退出表达”之间的差距。

### 14.4 转换路径

T1—T7 用于描述从库存、搜索、试用到成功、失败和回流的过程。它们不是互斥群体，按标签出现率或组合路径报告。

### 14.5 样本说明

- 120 条探索样本与 60 条关键案例参与了概念发现，不得作为无偏模型测试集；
- 关键案例样本经过目的性挑选，类别数量不能用于估计总体比例；
- demo 与正式模型验证必须从未见过的剩余语料中重新抽样。

## 15. 从 v1 到 v2 的标签映射

| v1 标签 | v2 处理方式 |
|---|---|
| 价值认同型 | 拆入 MR1、MR2、MR3、MR4、MR5、MX1、MX7 等具体机制 |
| 社会信号型 | 危机语境主要拆入 MX5、MX6；常态身份/面子价值如需保留，应另建 T0 基线模块 |
| 安全恐慌 | MX1；若重点是不相信检测，则同时或改标 MX2 |
| 立场抵制 | 拆入 MX3、MX4、MX5、MX6，并另以 D1/D2记录公开话语行为 |
| 理性辩护 | MR5；若理由是风险不可避免，则 MR6 |
| 摆烂虚无 | MR6；必要时在情绪备注中保留犬儒/疲惫表达 |
| 割舍挣扎 | O2/O3 与 MR1—MR4、T1/T2/T5 的组合，不再作为单独大类 |
| 替代转投 | T2—T7，并结合 O2—O4 |
| 国货红利 | 通常表现为 MX8 与 T2—T4；民族身份内容另标 MX5 |
| 主题无关/上下文缺失 | 数据质量字段与 O7，不再与消费机制混放 |

## 16. Demo 方案

### 16.1 Demo 的目的

第一轮 Demo 先不追求一口气证明整套方法，只确认两件事：

1. LLM 是否能够稳定执行标注，并且按层级输出；
2. 哪些字段仍存在系统性歧义。

### 16.2 Demo 样本

- 36 条全新未见文本，已于 2026-09-03 用固定随机种子 `20260903` 抽出；
- 已经排除此前为了归类和编码使用的 120 条探索样本与 60 条关键案例；
- demo样本从资生堂、SK-II、花王的 T1/T2 中抽取；
- 覆盖主贴正文与热门评论，同时包含 24 条一般随机文本与 12 条危机富集文本，并在独立审计清单中保留抽样层标记；
- 研究者与外部模型的标注输入不显示 `crisis_flag`、抽样层或原始行号；
- Demo 自身不用于估计总体占比；正式全量分析时，这些原始记录仍按统一规则回到完整语料中。

### 16.3 标注顺序

1. 研究者先在不知道 AI 结果的情况下制作 reference annotation；
2. 冻结 reference，不再因看到 AI 答案而静默修改；
3. 将相同 codebook 与文本交给外部 AI，不提供研究假设、既有答案或案例分组；
4. 同一模型在三个彼此独立的新对话中运行三次，检查自洽性；
5. 先计算一致率，再阅读分歧案例；
6. 若需修改 codebook，版本升为 v2.1，原 demo 变为开发材料，并重新抽取最终 holdout。

### 16.4 推荐 AI

**第一轮优先使用 Gemini 的全新对话作为外部 AI 标注者。**

理由：Claude 参与过 v1 的文档形成，ChatGPT 参与过 v2 的文档形成；Gemini 在三者中与现有设计过程最独立。

注意：

- 使用全新对话，不启用含 BPLL 历史的项目上下文或记忆；
- 只提供冻结版 codebook、目标品牌字段、文本和固定 JSON 输出格式；
- 不告诉 AI 哪类是研究者最关心的类别；
- 研究者使用的是聊天会员而非 API，因此无法严格锁定 temperature，故而需要三次独立重复；
- 第一轮通过后，可用 Claude 作为第二模型做稳健性检查。

### 16.5 Demo 达标线（暂定）

| 对象 | 指标 | 建议达标线 |
|---|---|---|
| R 目标品牌关系 | 原始一致率 + Gwet’s AC1 | agreement ≥ 0.90；AC1 ≥ 0.80 |
| O 消费结果 | 原始一致率 + Gwet’s AC1 | agreement ≥ 0.85；AC1 ≥ 0.80 |
| 关键派生判断：既有客户退出/非退出 | precision、recall、F1 | precision 与 recall 均 ≥ 0.85 |
| T 转换过程 | micro-F1、Jaccard | micro-F1 ≥ 0.80；Jaccard ≥ 0.75 |
| M 机制标签 | micro/macro-F1、逐标签 F1 | micro-F1 ≥ 0.80；出现 ≥5 次的标签 F1 ≥ 0.70 |
| AI 三次重复 | 同上 | 不得明显低于 AI—研究者一致率 |

36 条只是用来发现工作流程障碍。若某标签在 Demo 中少于 5 个正例，不单独判定它通过或失败，只做案例审查。
