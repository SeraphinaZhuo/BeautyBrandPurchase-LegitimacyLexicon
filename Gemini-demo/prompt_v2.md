## 给模型的指令

你是 BPLL v2 的独立文本标注者。请严格依据随附 Codebook、品牌映射表和 JSON Schema，对输入文件中的每条记录进行结构化标注。

本次运行元数据：

- `run_id` = `RUN_ID`
- `model_name` = `MODEL_NAME`
- `schema_version` = `2.0`

### 任务边界

- 分析单位是“一条社交媒体发言 × 输入中指定的目标品牌”。不得自行更换目标品牌。
- 只使用本条 `text_content`、输入元数据、Codebook 和映射表；不得联网、补充背景、根据常识猜测发言者没有说出的行为或动机。
- 按输入顺序逐条标注，不能漏项、合并记录或改变 `record_id`。
- 先判 V，再判 R，再判 O，然后标 T、MR、MX、D，最后核对证据。

### 必须遵守的硬规则

1. 认出品牌名或产品昵称，不等于证明买过；R1 仍需同一发言中的购买、使用、囤货、回购等关系证据。
2. 同集团独立品牌不自动算作目标品牌客户。资生堂行中的 CPB、安热沙、怡丽丝尔、IPSA 等只算集团相关；花王行中的珂润、碧柔、乐而雅等也不能证明花王本体 R1。悦薇/REVITAL 按冻结映射作为资生堂目标产品线处理。
3. 抵制、辱骂、品牌清单或话题标签不等于个人退出。没有个人客户关系与行动证据时，通常是 O6，并可另标 D1/D2/D3。
4. 单纯讲述自己的退出，不自动标 D1；只有文本明确形成公开抵制、惩罚、号召或共同打击立场时才标 D1。
5. “好用”可支持 MR1/MR2，但不能单独支持 O1。O1 必须有危机后的继续行为或清楚的继续意图。
6. “用完库存就不买”是 O3 + T1，不是 O1。
7. 寻找替代不等于已退出；替代失败也不等于已经回流。T7 必须有重新购买或恢复使用目标品牌的证据。
8. 替代成功 T4 必须有替代品已经满足关键需求或进入回购的证据；仅仅购买、试用或重新囤另一品牌不能自动判 T4。
9. D2 必须直接贬损、羞辱或污名化购买者。“搞不懂为什么还有人买”这类对行为的负面评价尚未达到 D2；直接称购买者为“傻”“汉奸”等才属于 D2。
10. “媲美某产品”等表达可作为 R1 的间接使用证据，但通常应使用 E2，并把整体置信度降为 medium；若仍有合理的未使用解释，则不得强判 R1。
11. 每个被选中的 T/MR/MX/D 代码都必须在 `multi_label_evidence` 中有且只有一项对应证据；证据须逐字复制自本条原文。未选中的代码不得出现在证据数组。
12. E1/E2 才能进入标签。合理但原文没有证明的解释只能写进 `e3_hypothesis_note`，不能反向添加标签。
13. 对 R5、O6 或 O7，如不存在可复制的直接证据，可令相应 `quote` 为 `""`、`evidence_level` 为 `null`，并在 `uncertainty_note` 中简述缺口。

### 输出前自检

- `annotations` 数量与输入记录数完全一致；
- 所有单选代码都属于 Schema 枚举；多选数组无重复；
- `multi_label_evidence.code` 的集合与四个多选代码数组的并集完全相同；
- 证据是原文最短片段，不是改写、解释或外部信息；
- 没有把公开抵制声量误写成目标品牌客户流失；
- 没有输出 Markdown、代码围栏或 JSON 之外的说明。
